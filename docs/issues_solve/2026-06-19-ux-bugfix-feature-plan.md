## 2. Cross-cutting design decisions (apply across items)

1. **Active structure = plain `POSCAR`.** Every structure-producing tool keeps
   writing the canonical `POSCAR` as the "active" pointer. The *labeled* copy is
   where identification/operation tags live (BS1).

2. **Operation-tagged labeled copies (BS1).** One consistent rule:
   ```
   generate_poscar  → POSCAR_Si
   make_slab        → POSCAR_Si_slab111
   make_supercell   → POSCAR_Si_2x2x1
   add_vacuum       → POSCAR_Si_vac
   vacancy          → POSCAR_NaCl_vac-Na
   substitution     → POSCAR_NaCl_sub-Na-K   (NOT a fake "KCl" — it is a dilute defect)
   interstitial     → POSCAR_NaCl_int-K
   ```
   Defect tools already compute a `defect_name`; feed it into the filename.

3. **Provenance line (G1).** Line goes where each format allows a comment:
   - POSCAR/CONTCAR → **line 1** (title line) — combine with BS1 tag, e.g.
     `Si slab(111) — Generated by Materia 2026-06-19`.
   - INCAR/KPOINTS → leading `! Generated by Materia …`
   - CIF → leading `# Generated by Materia …`
   - XYZ → comment on **line 2** (per format).
   - **CSV → special-case**: a naive comment line breaks pandas/Excel parsing.
     Either omit, or use a `#`-prefixed line readers can skip.

4. **VASP folder = exactly the 4 files VASP needs** (`POSCAR, INCAR, KPOINTS,
   POTCAR`). No labeled POSCAR copy and no POTCAR.spec when a real POTCAR exists.
   `generate_vasp_inputs` writes into a **task subfolder** (`vasp_inputs/<task>/`)
   to avoid clobbering the active POSCAR at the session root.

5. **Agent over-calling guard (BS2 + V3).** The agent loops up to
   `MAX_TURNS = 6` and re-issues the same tool when a result looks unchanged
   (slab of Si → still "Si"). Two-pronged fix:
   - Make results unambiguous (BS1 distinct names + clear "operation done" message).
   - Add a guard that detects an identical/near-identical repeated tool call in a
     turn and short-circuits instead of re-running.

## 3. Phased execution order

Sequenced so shared helpers land first and each phase is independently verifiable.

### Phase A — Naming & provenance foundation (BS1, G1, V1) — ✅ DONE 2026-06-19
- `write_poscar` now takes `tag=` (operation-tagged labeled copy) and
  `named_copy=` (skip the copy for VASP folders), and stamps the POSCAR title
  line (line 1) with `"<formula> <tag> — Generated by Materia <date>"`.
- BS1 tags wired through: make_slab→`slab111`, make_supercell→`2x2x1`,
  add_vacuum→`vacuum-c`, vacancy→`vac-Na`, substitution→`sub-Na-K`,
  interstitial→`int-K`, analyze_symmetry→`prim`/`conv`. All envelopes now use the
  writer's returned `files_written` (no more hardcoded `POSCAR_{formula}`).
- V1: `vasp/service.py` writes the canonical POSCAR only (`named_copy=False`).
- G1: INCAR (`# INCAR generated by Materia`) and KPOINTS (`Automatic mesh —
  Materia`) were already branded; added provenance to POSCAR line 1 and to the
  `convert` CIF/POSCAR outputs. XYZ left alone (extXYZ line 2 = lattice metadata).
- **Verified:** standalone logic test vs container pymatgen (tagged names,
  `named_copy=False` → POSCAR only, CIF+POSCAR comment round-trip re-parse) and
  `py_compile` on all four edited files.
- **N1 moved to Phase F** (it touches the optimize/MD workers, not structure
  writing).

### Phase B — VASP correctness (V2, V4) — ✅ DONE 2026-06-19
- V2: `potcar.write_potcar_spec` now writes `POTCAR.spec` **only as a fallback**
  when no real POTCAR can be assembled; with the licensed PAW lib it writes
  `POTCAR` alone. `service.py` already added spec/potcar conditionally, so the
  set is now exactly `POSCAR, INCAR, KPOINTS, POTCAR` (or `…/POTCAR.spec` w/o a
  license).
- V4 review: INCAR tasks correct (opt IBRION=2; static/band IBRION=-1 NSW=0; DOS
  ISMEAR=-5 tetrahedron; elastic IBRION=6 ISIF=3; phonon_dfpt IBRION=8; MD
  IBRION=0); ISIF map none=2/shape=5/full=3; KPOINTS density 40 default / 60
  DOS+dense; POTCAR variants from curated table (Na_pv, Ti_sv, …).
- **Verified in the api container (real app modules + mounted PAW lib):**
  - real-POTCAR path → `[INCAR, KPOINTS, POSCAR, POTCAR]`, no spec, header
    `PAW_PBE Na_pv`, ENCUT 520 from real ENMAX.
  - no-license path → spec fallback, still 4 files, no labeled POSCAR copy.
  - labels Na_pv / Ti_sv / O correct; `py_compile` clean.

### Phase C — Optimize = only optimize (V3) + agent guard (BS2) — ✅ DONE 2026-06-19
- V3: `optimize_structure` now defaults `emit_vasp_inputs=False` — it does only the
  relaxation of the active structure; VASP inputs are emitted only if explicitly
  requested. (MD/elastic keep their own flag; only optimize was in scope.)
- BS2: `graph.py` agent loop now fingerprints each tool call by `(name + args)`
