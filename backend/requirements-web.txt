# ── Materia LITE WEB requirements (Part B) ───────────────────────────────────
# Slim, torch-free dependency set for the free-tier web deployment. It runs the
# 15 INSTANT tools only (search, VASP input generation, structure building,
# defects, symmetry, file ops). The 6 heavy ML-potential simulations are gated
# off (ENABLE_HEAVY_TOOLS=false), so their deps are intentionally NOT installed.
#
# Verified safe: every torch/mace/mattersim/phonopy/seekpath/matplotlib import in
# the codebase is lazy (function-level, ImportError-guarded) and lives only in the
# gated heavy paths — so `import app.main` succeeds without them. The Dockerfile.web
# build runs that import as a smoke test, failing the build if this ever regresses.
#
# Diff vs requirements.txt: DROPPED torch, torchvision, torchaudio, mace-torch,
# mattersim, e3nn, phonopy, seekpath, matplotlib (and the ATAT C++ build).
