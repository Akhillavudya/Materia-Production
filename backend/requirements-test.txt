# mattersim, phonopy …) which the *web* process never imports. The unit tests and
# the structure/VASP validation tests only need the web + materials-core libraries,
# so CI installs this subset and runs the whole suite in well under a minute —
# instead of building the ~4 GB image just to run pytest.
